# Rail Gun (Fabric 1.21.1)
Hold right-click ~1s to charge (needs iron ingots as slugs, free in creative), release to fire.
Build: copy gradlew/gradle/wrapper from the Fabric example mod (or run `gradle wrapper`), then `./gradlew build`.
Jar lands in build/libs/. Tweak damage/range/charge in RailgunItem.java, visuals in client/RailgunFX.java.
